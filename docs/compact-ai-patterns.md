- **Reasoning trace:** `F.aiResearchActivity` uses one disclosure with unnumbered single-line steps. Reading, calculating, drafting and completion determine current/complete/queued indicators. Source links or source popovers are inside a nested reading disclosure. Labels truncate visually, with full text retained in the DOM and title. Motion uses the existing shimmer and a 4px staggered entry, inspired by Spectrum’s step reveal. No private model reasoning or live AI service is supplied; these are illustrative activity labels.
- **Message actions:** `F.aiMessageActions` composes shared ghost icon buttons for copy, regenerate, positive and negative feedback. Copy includes response content, excludes controls and hidden source dialogs, and reports actual clipboard success or failure. Ratings toggle exclusively per response. Retry and feedback dispatch local `forma:regenerate` / `forma:feedback` events. No remote generation or rating persistence is implied. The regular/filled thumb and paired clockwise-arrow icons use unchanged official Phosphor assets under the existing MIT license.
- **Voice waveform:** one `F.voiceWaveform` renderer serves the Motion/Waveform specimen and the existing prompt bar. Individually phased bars vary speed and amplitude while using shared color, spacing and timing tokens. In the prompt, the waveform appears only after recognition starts and clears on end, error, stop or cleanup. It is an illustrative listening animation, not measured microphone amplitude. Existing browser speech recognition behavior is retained.
- **Task rows:** AI progress / Stages follows the user's complete TaskRows source: a 480px maximum box, fine dividers, native row buttons, status icons, one-line title, optional detail, shared pill badges and a downward chevron. One optional note can be expanded at a time using a 240ms grid-row transition. Compact rows have no disclosures. See the source refinement below.
- **Search:** AI progress / Search and AI response / Search share `F.aiWebSearch`. Each result is a single row: source icon, truncating title, reading state or chevron. Only http(s) or permitted fragment links are rendered as links. Empty results have a short explicit state. Examples do not run a web search.
