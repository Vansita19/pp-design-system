# Workspace logo

The Pitch Protocol workspace uses `dist/assets/pitch-protocol-logo.png`, based on the logo supplied on 10 October 2026. Its exterior background is transparent; the blue tile and white connected-node symbol remain visible.

The shell displays it at 28 × 28 px using the existing spacing token and `object-fit: contain`. The standalone HTML embeds the same image for offline use. Replace the shared asset and run `python3 checks/package.py` for future updates.

The built-in image tool was used with this edit instruction: “Remove only the white exterior background outside the blue rounded-square tile; preserve the blue tile and white connected-node symbol; use a transparent background.”
