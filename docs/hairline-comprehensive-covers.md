# Comprehensive pattern covers

Seven new catalogue covers use the supplied, unchanged `vendor/hairline/skills/hairline-create/SKILL.md`, its rules and the existing `cover-utility-patterns.js` recipe pipeline. The chosen concepts have a complete physical rest pose; none uses an interface icon as its illustration.

| Page | Object and identifying features | Pointer response |
| --- | --- | --- |
| Conversation | Telephone exchange with receiver bells, finger dial and recessed line-key bank | Lifts the receiver, dial or key bank |
| Company report | Open ledger with layered pages, fore-edge tabs and a binding clasp | Lifts a page block or clasp |
| Evidence trace | Examination carriage with specimen slide, concentric lens mount and reference cassette | Lifts the slide, lens assembly or cassette |
| Collection workspace | Archive cabinet with three extended drawers, runners, divided wells and recessed pulls | Draws out the selected drawer |
| Note editor | Drafting clipboard with layered ruled stock, sprung clamp and pencil trough | Lifts the paper, clamp or pencil |
| Navigation | Indexing turntable with bearing platter, bridge rail, detent saddle and release lever | Lifts the selected mechanism |
| Account flow | Access-card reader with contact card, scan head and mechanical latch | Raises the card, scan head or latch |

`dist/cover-comprehensive-patterns.js` registers recipes after `hairline-scenes.js` and before `hairline-adapter.js`. It has no dependency on another cover recipe file. The shared adapter owns the unchanged official geometry, fixed rest anchors, 700ms discrete tween, distance stagger, single highlight, reduced motion and teardown. The same recipes are automatically discovered by both the geometry checks and official bench builder.

## Validation and look checklist

`node checks/comprehensive-pattern-covers.cjs` passes for all seven covers and 105 rest/intermediate/extreme poses. It checks structural detail, distinct scenes, finite geometry, three fixed rest anchors, one highlight, frame clearance, low/high intensity, reduced-motion return and complete cleanup. `node checks/build-hairline.mjs --validate` built and passed the unchanged official validator for all 75 recipes, including these seven. The original kernel and bench were not edited.

The figures were **not looked at in a browser**. SVG exports are available from `COVER_EXPORT_DIR=/tmp/forma-comprehensive-cover-review node checks/comprehensive-pattern-covers.cjs`. A native thumbnail attempt was blocked by the execution sandbox, so no new raster or screenshot review is claimed.

| Look check | Code evidence or remaining limit |
| --- | --- |
| Silhouette at 240px | Each recipe names and builds the physical features listed above; thumbnail readability remains visually unverified. |
| Composed rest | Each recipe uses three groups at differing rest heights, fitted housings and a deliberate `S.focus` order. |
| Spread from pointer | Shared `coverMount.choose` uses the selected lift plus a smaller neighbor response and distance-based 40ms delay. |
| Stable hit tests | `tracks.hit` is projected once from rest anchors; tests hold every anchor while parts move. |
| Rounded, restrained construction | Every solid goes through official `prism`/`solid`; concentric rounds use the adapter's higher-resolution ring path. |
| Opaque paint order | Bases and rear fittings precede their assemblies; each assembly's cover precedes its attached grooves. The near cabinet upright is painted last. Occlusion still needs visual review. |
| One highlight | Tests inspect one highlighted silhouette at rest and throughout all selected poses. |
| Read-out | Every fixed anchor returns its group number, and pointer leave returns `rest`. |
| Frame bounds | All checked poses fit inside 400×320 with stroke clearance through the real kernel geometry. |
| Both themes | No recipe defines a color or fill. The unchanged palette supports both themes; light/dark raster appearance is unverified. |
| No words or icons | Recipes contain only physical boxes, rings, seams and punched details; official validation passes. |
| Clean page | Source syntax, real geometry and lifecycle checks pass. Browser console and native pointer events were not tested. |
| Empty state | Not applicable: these seven covers depict working physical instruments. |

Standalone benches use the existing shared tour stops `[140,140]`, `[245,165]`, `[200,210]`, then leave. The tour was not visually judged. The catalogue itself responds to the reader's pointer and does not run an ambient loop.
