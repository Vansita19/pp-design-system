# Feedback motion

[AlignUI Tooltip](https://www.alignui.com/docs/v1.2/ui/tooltip) provides the reference for a fade, slight scale and directional movement on entrance and exit. Forma retains its existing compact dark surface and top/bottom placements. Hover opens after 300ms; keyboard focus opens immediately. A 100ms leave grace lets the pointer cross the gap into the tooltip. Hovering its content keeps it open. Escape dismisses and suppresses reopening until the current hover/focus interaction ends. The tooltip remains noninteractive, uses a unique description ID, and never takes focus.

The surface animates over the existing 160ms fast duration with a 4px movement and 95% scale. Reduced-motion and live pause changes settle the effect immediately. Unmount cancels pending delays, animation objects, preference observers and listeners. Reversing an exit cancels its stale completion, so it cannot hide a reopened tooltip.

## Installed Spectrum toast stack

The earlier independent toast animation was removed on 2026-10-09. Forma now runs the actual `AnimatedToastStack` and `useAnimatedToastStack` from the public [Spectrum toast-stack registry](https://ui.spectrumhq.in/r/toast-stack.json), documented on [Spectrum UI](https://ui.spectrumhq.in/docs/toast-stack). The original `components/motion/animated-toast-stack.tsx` and `lib/ease.ts` are vendored byte-for-byte under `vendor/spectrum-toast`; `source.json` records their SHA-256 hashes. The registry credits beUI. Spectrum's repository Apache-2.0 license and installed dependency notices are included.

This is a scoped React island, not a native recreation. The original source retains its Motion layout spring (stiffness 420, damping 34, mass 0.75), `AnimatePresence` pop-layout, entrance (22px rise, 0.96 scale, 10px blur), 180ms horizontal exit, swipe dismissal, and 280ms status/content transitions. Static placement keeps each specimen inside its preview without a portal. Initial specimens remain stationary, as the original `initial={false}` specifies. Newly shown loading toasts change to success after 1.8 active seconds, demonstrating the source's status morph.

The Forma wrapper supplies the existing tone/count/action controls, Hugeicons Stroke Rounded status icons through the supported `icons` prop, token-backed surface/text/status colors and typography through `classNames`, and focus recovery. The source's dismiss button keeps its native semantics and behavior. The build resolves the source's icon-library import to `hugeicons-react.tsx`, which renders SVGs through the canonical `F.icon` renderer, including the 16px close glyph. No hidden alternate icon, mask or copied geometry remains. All toast icons use Hugeicons Stroke Rounded with a 1.25px stroke at sizes up to 16px and 1.5px above 16px; the shared renderer retains non-scaling strokes. Forma uses the original state hook with zero native duration and a scoped lifetime timer to preserve six-second expiry that pauses for hover, keyboard focus, hidden documents and local/global pause. Initial examples do not expire. Pausing settles transforms/blur visually and pauses the spinner; Motion may finish its internal animation while paused. Reduced motion uses the original component behavior plus a spinner/transform override. This is documented host integration, not an alteration of the vendored animation source.

`vendor/spectrum-toast/build.mjs` bundles production React and Motion into `dist/spectrum-toast-runtime.js` and produces `dist/spectrum-toast-runtime.css`. The Tailwind build excludes preflight and prefixes every selector to `.pp-spectrum-toast-host`; keyframes and custom-property registrations remain valid top-level rules. There is no runtime network dependency. Rebuild with `npm ci` then `npm run build` inside the vendor folder. The lockfile pins the installed dependencies. The former icon package is no longer installed or bundled; the unchanged registry retains its historical dependency declaration. The build rejects any accidental inclusion of that package's code. Source, license, build files and lockfile belong in the source archive; `node_modules` does not.

[AlignUI Toast](https://www.alignui.com/docs/v1.2/ui/toast) and [Notification](https://www.alignui.com/docs/v1.2/ui/notification) remain earlier motion references only. No separate Notification page was added.

Checks: `checks/tooltip.cjs` covers hover delay cancellation, keyboard focus, pointer persistence, animated exit, reversal/stale completion, Escape suppression, live preference changes and cleanup. `checks/action-feedback.cjs` covers native action/undo behavior and island mount/disposal. `checks/spectrum-toast.cjs` verifies immutable source hashes and the actual production React bundle in happy-dom: stack capacity, focus recovery, timer pauses, expiry, Undo, status morph, unmount, and actual SVG family/stroke attributes. happy-dom’s incomplete Web Animations implementation is disabled in that test so Motion uses its JavaScript animation fallback; errors are not suppressed. Simulated events and animation objects do not establish browser appearance, touch interactions or assistive-technology conformance.
